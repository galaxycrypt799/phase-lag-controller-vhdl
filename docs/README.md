# Tài liệu

`FPGA_VHDL_report.pdf` là báo cáo đồ án gốc bằng tiếng Việt. Báo cáo trình bày
mục tiêu hệ thống, kiến trúc CPU vi chương trình, bộ điều khiển Phase-Lag,
định dạng fixed-point và kết quả mô phỏng được trình bày trong tài liệu.

README ở thư mục gốc của repository cung cấp phần hướng dẫn nhanh bằng văn bản,
cấu trúc mã nguồn, thứ tự biên dịch và các entity testbench.
# Project documentation

`FPGA_VHDL_report.pdf` is the original Vietnamese project report. It describes the system goals, microprogrammed CPU, Phase-Lag controller, fixed-point representation, and simulation results presented in the report.

See the root `README.md` for an accessible project overview, source layout, compile order, and testbench list.
